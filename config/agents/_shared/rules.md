# 全局规则

## 语言要求
- 所有代码注释、文档字符串和日志信息必须使用**英文**。
- 所有面向用户的输出（报告、分析描述、图表标题、摘要）必须使用**简体中文**。
- 所有 Python 代码遵循 Google Python 风格指南。

## 代码质量标准
- 所有函数签名必须包含类型提示。
- 所有公共模块、函数、类和方法使用 Google 风格的文档字符串。
- 文件行数应尽量控制在 1000 行以内。

## 可复现性
- 对于随机算法，始终包含锁定随机种子（PyTorch、NumPy、Python random）的代码。
- 不允许静默失败 - 明确抛出异常，而不是使用默认值掩盖错误。

## 命名规范
- 使用物理/数学含义的命名（如 `synaptic_weight`、`angular_velocity`），而非通用名称。
- 在 NumPy/PyTorch 上下文中，优先使用向量化操作而非显式循环。
